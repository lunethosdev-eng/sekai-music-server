Endpoint Único de Catálogo Completo

Obtén todo el catálogo con 1 sola llamada API (incluye letras, audios SoundCloud/YouTube y arte HD).

GET
https://sekai-music-server.onrender.com/api/v1/catalog

Ejemplos de Integración (1 sola línea / petición)

JavaScript (Fetch) 
const res = await fetch('https://sekai-music-server.onrender.com/api/v1/catalog');
const { total, catalog } = await res.json();
console.log(`Cargadas ${total} canciones:`, catalog);
Python (Requests) 
import requests
data = requests.get('https://sekai-music-server.onrender.com/api/v1/catalog').json()
print(f"Total canciones: {data['total']}")
